# Kids Game

아이가 수업에서 만든 게임을 모아 두는 저장소입니다.

## 알록달록 블록 탐험 3D

`block-explorer-3d/index.html` 파일 하나로 된 1인칭 3D 게임입니다. 브라우저에서 파일을 열면 바로 실행됩니다 (인터넷 연결 필요).

- 고양이 탐험가가 되어 숲, 사막, 얼음 왕국, 우주를 돌아다니며 퍼즐 블록을 모읍니다.
- 모은 블록을 8x8 퍼즐판에 놓아 가로나 세로 한 줄을 채우면 코인을 받습니다.
- 컴퓨터: WASD로 이동, 마우스로 둘러보기, Space로 점프
- 폰: 화면 왼쪽을 밀어 이동, 오른쪽을 밀어 둘러보기
